# Student Performance Analysis (MySQL)

Analysis of student marks using SQL.

**Tables:** students, subjects, marks (10 students, 3 subjects)
**Concepts used:** JOIN, GROUP BY, HAVING, ORDER BY, LIMIT, AVG, SUM, CASE

## Findings
- Top 5 students by total marks: Charan, Gayathri, Anu, Indu, Farhan
- Pass percentage (pass mark 50): Python 80%, DBMS 90%, Maths 70%
- Maths had the lowest pass percentage
- 6 of 10 students have an average of 60 or above
